## 🎯 プロジェクト概要

「simple NEWS podcaster」は、ユーザーが自身で難易度を設定できるニュースポッドキャストアプリです。Team:03「PodFresh」として開発しました。

### 解決したかった課題
経済ニュースを通勤中や歩きながら聞く際、以下の課題がありました。
* 知らない用語が出ると内容の理解が難しくなる。
* 既存のポッドキャストでは、ユーザーに合わせた難易度調整や分かりやすい解説がされていない。

### AIによるアプローチ
専門性に縛られず、難しいニュースをAIがレベルを落として要約・解説します。スクレイピングしたニュースを3つの難易度ごとに要約し、音声出力に最適化したプロンプトを用いてテキスト化しています。

## 🛠 使用技術 (Tech Stack)

* **フロントエンド:** Flutter (アプリのUIベース)
* **LLM:** Gemini API (ニュースの要約と難易度調整)
* **音声合成:** VOICEVOX API (Geminiで生成したテキストの音声化)
* **データ取得:** Bloomberg (ニュース文のスクレイピング)
